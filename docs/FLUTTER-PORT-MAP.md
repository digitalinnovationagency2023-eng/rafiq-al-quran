# Rafiq Al-Quran: Android to Flutter porting map

Produced 2026-11-07 from the 1.4.2 Java app (`mobile/android`). The Flutter app lives in `mobile/flutter` and is the iOS edition (it can later replace the Android app too). All Java paths below are under `mobile/android/app/src/main/java/com/rqmbooks/rafiqalquran/` (written `<pkg>/`).

Three things to know first:

- **The dataset is not in the repo.** `app/src/main/assets/` only holds `fonts/`. The TSV files are generated by `mobile/android/scripts/exportAssets.js` from a SQLite database that is also gitignored (`server/data/`, `*.db`). Run `npm install`, `npm run import:quran -w server`, then `node mobile/android/scripts/exportAssets.js` to produce them. The one committed data file is `mobile/android/scripts/data/quran-meta.tsv`. Generated sizes (7 Nov 2026): chapters.tsv 4 KB, quran.tsv 1.36 MB, translations.tsv 11.7 MB, translation-meta.tsv 1 KB, lexicon.tsv 12 KB, provenance.tsv 269 B, quran-meta.tsv 100 KB.
- **Every screen is built in code.** No layout XML. Styling helpers live in `<pkg>/Ui.java`.
- **Almost all text is hard-coded English in Java.** `res/values/strings.xml` has 2 strings and there are no other locale folders.

## 3. Data

Build: `server/scripts/importQuran.js` downloads from Quran.com API v4 (`/chapters?language=en`, `/quran/verses/uthmani`, `/resources/translations`, `/quran/translations/{id}`), writes raw JSON + SHA-256 to `server/data/raw/`, builds SQLite `server/data/quran-app.db` (schema `server/src/db.js` L8-150). `mobile/android/scripts/exportAssets.js` writes the TSVs. `fetchQuranMeta.js` produced the committed `scripts/data/quran-meta.tsv`.

Translations (`importQuran.js` L31-41): en Saheeh International (20), ur Jalandhari (234, rtl), id Indonesian Ministry (33), bn Mujibur Rahman (163), tr Diyanet (77), fa IslamHouse (135, rtl), ms Basmeih (39), sw Al-Barwani (49), fr Hamidullah (31). All `license_status = "unverified"`. Arabic has no translation rows.

Asset files (UTF-8, tab-separated, no header, empty lines skipped), read by `<pkg>/Assets.java`:

| File | Columns | Rows |
|---|---|---|
| `chapters.tsv` | `id, name_arabic, name_simple, verses_count, revelation_place` | 114 |
| `quran.tsv` | `verse_key, text_uthmani` | 6236 in mushaf order |
| `translations.tsv` | `lang, verse_key, text` | 9 × 6236 |
| `translation-meta.tsv` | `lang, title, author, direction, license_status` | 9 |
| `lexicon.tsv` | `key, arabic, en, ur, id, bn, tr, fa, ms, sw, fr`; comma-separated terms per cell (source `server/src/services/lexicon.js` `CONCEPTS`) | ~96 concepts, ~32 `entity-*` |
| `provenance.tsv` | `quran\t{dataset}\t{version}\t{source_url}\t{checksum}\t{imported_at}`, then `imported-at`, `verse-count`, `chapter-count`, `translation-count` | 5 |
| `quran-meta.tsv` | `#` comments, then `verse_key, juz, page, hizb` | 6236 |
| `fonts/Amiri-Regular.ttf` | OFL | 431 KB |

Loading (`Assets.java`): `dataset()` parses everything except translations on first use; `ensureLanguage(lang)` loads only that language's rows (English always, plus the UI language); `meta()` loads `quran-meta.tsv`. For Flutter: bundle under `assets/data/`, split translations per language, parse in an isolate.

## 4. Network (`<pkg>/Api.java`)

Base URL `https://rqmbooks.com/rafiq-api` (`strings.xml` L7). Empty = fully offline. `Accept: application/json`, 12 s connect timeout. Status ≥ 400 throws with the body; a message containing "429", "quota", "daily ai" or "ai limit" is a quota error (MainActivity L1583-1586).

| Call | Path | Read timeout | Request | Response |
|---|---|---|---|---|
| `assistantStatus` | GET `/api/assistant/status` | 8 s | none | `{enabled, providerConfigured, limits:{deviceDaily:10,…}, donationUrl}`; app reads `enabled` |
| `appVersion` | GET `/api/app/version` | 8 s | none | `{versionCode, versionName, url}` (server defaults 20 / 1.3.5; iOS needs its own store URL or a platform field) |
| `assistant` | POST `/api/assistant` | 45 s | `{text (≤1000), language, attachment?:{name, mime, dataBase64}}` (image ≤5 MB png/jpeg/webp) | `{enabled, intent:"smalltalk|question|offtopic|attachment", reply|null, searchTerms:[]|null, imageText|null}`; 503 when AI off, 429 over budget |
| `assistantAnswer` | POST `/api/assistant/answer` | 60 s | `{question (≤500), language, verseKeys:[≤18], facts?:[1 ≤300], history?:[{role, content ≤400}] ≤6}` | `{enabled, answer, citations, verseLanguage, cached}` |
| feedback | POST `/api/feedback` | 15 s | `{category, description, language, verseReference?, contact?, consent, diagnostics?:{platform, language}}` | 201 `{id, status, message, whatsapp}` |
| admin | GET `/api/admin/{summary, datasets, feedback?limit=10, audit?limit=10, premium/features, reciters}` | 15 s | header `x-admin-token` | JSON |

Offline: reading, surah search, retrieval answers, facts, conversation rules, study tools, chat history, text/.docx attachments. Online: AI intent, OCR, deep answer, update check, feedback, admin, recitation audio.

AI flow (`submit`/`performSubmit`, L1253-1377): 1) `Conversation.classify`; 2) one-time consent dialog (L1286-1300; "Use offline only" turns AI off); 3) if AI available and enabled, `callAi`: smalltalk/offtopic reply shown directly, otherwise `searchTerms` replace the search text; 4) `Facts.match`, then `AnswerComposer`; 5) `deepenAnswer` only when confidence ≥ 0.35, accepted only if it cites at least one shown verse key (`hasGroundedCitation` L1571) and shares a question word (`hasQuestionOverlap` L1555). Device quota `AI_DAILY_LIMIT = 10` per `yyyy-MM-dd` day (L81, L1539-1552); "Daily AI limit reached" card (L1594).

Recitation (PlayerActivity): CDN `https://verses.quran.com/` + `String.format(template, chapter, verse)`. Reciters (L58-62): Mishary Rashid Alafasy `Alafasy/mp3/%03d%03d.mp3`; Abdul Basit Abdus Samad (Murattal) `AbdulBaset/Murattal/mp3/%03d%03d.mp3`; Muhammad Siddiq Al-Minshawi (Murattal) `Minshawi/Murattal/mp3/%03d%03d.mp3`. Example 2:255 Alafasy → `https://verses.quran.com/Alafasy/mp3/002255.mp3`. Auto-advances verse by verse; at the end of a surah continues to the next if `continuous` (car mode or `continuousListen` pref, default true), up to 114. Audio focus, media session (play/pause/next surah/previous surah), keeps playing when locked. Flutter: `just_audio` + `audio_service`/`audio_session` with `UIBackgroundModes: audio`.
